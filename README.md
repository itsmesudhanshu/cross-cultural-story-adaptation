# Cross Cultural Story Adaptation using NLP and LLMs

## Overview
This project adapts Western stories into Indian cultural settings while preserving the original plot, meaning, and moral lessons.

## Features
1.Rule-Based Story Adaptation
2.Named Entity Recognition (SpaCy)
3.Cultural Knowledge Base
4.Retrieval-Augmented Generation (RAG)
5.Gemini-based Story Adaptation
6.Semantic Similarity Evaluation
7.Streamlit Web Application

## Tech Stack
1.Python
2.SpaCy
3.Pandas
4.Google Gemini
5.Sentence Transformers
6.Streamlit
7.Git/GitHub

## Workflow
Story → NER → Knowledge Retrieval → Cultural Adaptation → Evaluation → Output
